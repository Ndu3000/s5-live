About the times. All times are South African time (SAST), based on the published Gautrain S5 weekday timetable (Sandton Station ⇄ Montecasino via Bryanston).

About live GPS. Bus positions come from Gautrain's bus-location feed every 10 seconds. The feed doesn't say which route a bus is on, so the app counts a bus as an S5 when it is driving along the S5 roads in the right direction, and pairs it with the timetable trip it is closest to. Arrival estimates assume the bus keeps to the timetable's pace from where it is now. If the bus is late, “leave by” still uses the scheduled time, so you never leave later than the timetable says. If it is early, “leave by” moves earlier. Route map © OpenStreetMap contributors.

About traffic. TomTom's traffic for each stretch of the route stretches or shrinks the timetable's minutes for that stretch. Live arrival estimates and the small expected times use it. Live traffic comes from TomTom when a key is set up, and otherwise from Gautrain's own buses: how fast each S5 bus has really been moving over the last few minutes. When live traffic is available, it replaces typical traffic for the next 15 minutes and blends back to typical over the following 45, and slow stretches are named.

Regular Gautrain buses don't run on weekends or public holidays. Traffic can delay buses; if yours is late, call the Gautrain bus information line on 010 223 1098.
